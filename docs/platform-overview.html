Business Context

Product: Smartphone-based contactless vital signs monitor using remote photoplethysmography (rPPG). The phone camera captures micro colour changes in facial skin via the green spectrum; the RGB signal is processed by cloud ML algorithms to return systolic/diastolic BP and pulse rate. No cuff, no hardware, no contact. Current state: Python/Flask inference, Azure-hosted, new container instance per assessment (~7p/assessment). ML pipeline is data-scientist-led with no formal model versioning. CI/CD not matured. Target: FDA-submission-ready engineering, under 1p per assessment, auditable ML pipeline, acquisition-ready.

AI Agents
🔍
Code Review Agent
Trigger: PR opened / updated
  • Reviews diff for quality and security patterns
  • Posts findings: CRITICAL / WARNING / INFO
  • Checks compliance field checklist
  • Cannot approve or block PR
✓
Compliance Agent
Trigger: PR raised
  • Verifies req → test → execution chain
  • Flags risk class inconsistencies
  • Posts traceability report to PR
  • Cannot block merge
📄
Documentation Agent
Trigger: merge to main / release
  • Drafts CHANGELOG from merged PRs
  • Drafts Software Release Record
  • Raises PR for human review
  • Cannot write to Qualio directly
⚡
Ops Agent
Trigger: PagerDuty / Grafana alert
  • Queries Grafana for related metrics
  • Queries Loki for log context
  • Creates GitHub incident issue
  • Cannot remediate or silence alerts
🧪
ML Validation Agent
Trigger: ML file change detected
  • Detects model weight / pipeline changes
  • Flags if change is a design change
  • Posts regulatory review recommendation
  • Cannot approve or block merge
