All documents in this repository are framed as reference architecture for "a Class IIa medical device company with these characteristics" rather than naming a specific organisation. This allows the repo to function as a credible, shareable professional portfolio piece applicable to any company fitting the profile, without appearing presumptuous before a formal engagement is in place.

Company-specific naming reduces reusability. Fully anonymous content with no specific details would be too vague to be credible. The current framing strikes the right balance. See **DEC-007**.
