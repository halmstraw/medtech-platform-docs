A shared set of Claude Code skills and templates (including `/proceed`, `/reflect`, and checklist-based step tracking) that automate an agentic software development lifecycle — spec, architect, implement, and post-implementation reflection. The toolkit addresses context-compaction drift by having Claude reference a checklist at each step, maintaining SDLC state across long sessions. For a Class IIa regulated platform, any adoption must validate that AI-generated artefacts (specs, architecture docs, test plans) satisfy traceability and change-control evidence requirements under IEC 62304 and the QMS.
