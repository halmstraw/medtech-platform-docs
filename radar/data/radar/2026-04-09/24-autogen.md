Microsoft multi-agent orchestration framework. Candidate for complex agent workflows where multiple agents need to collaborate (e.g., a compliance agent and a code review agent operating on the same PR). More powerful than a single-agent approach for some scenarios.

Assess before committing. The trust zone model requires that each agent has clearly scoped permissions — AutoGen's conversational multi-agent patterns need to be evaluated against these constraints. See Layer 14 (AI Engineering Strategy).
