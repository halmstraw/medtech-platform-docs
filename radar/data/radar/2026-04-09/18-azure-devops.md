Rejected. GitHub Actions achieves the same CI/CD outcome with less context switching given the existing GitHub footprint. Azure DevOps would add a second Microsoft platform without sufficient benefit. The audit trail, traceability chain, and developer experience are all better served by keeping everything in GitHub.

Do not use for new work. See **DEC-002**.
