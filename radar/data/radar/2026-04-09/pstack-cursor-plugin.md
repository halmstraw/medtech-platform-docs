pstack is an official Cursor plugin that provides a curated set of engineering skills and playbooks (e.g. `/poteto-mode`, `/architect`, `/arena`) to enforce rigorous, multi-model agent workflows and reduce AI-generated 'slop code'. It supports parallel subagent execution with structured handoffs and can self-personalise via `/automate-me` by mining past transcripts. For a Class IIa medical device context, pstack's lack of audit-trail integration, unproven traceability story, and dependency on the Cursor IDE make it worth monitoring but not yet trialling without a focused evaluation against IEC 62304 development controls.
