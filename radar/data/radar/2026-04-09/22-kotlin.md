Android mobile SDK. Native platform engineering. MVVM and Clean Architecture are the target patterns. The same rPPG signal capture abstraction principles apply across iOS and Android — platform-native implementations but a consistent architectural model.

The Android SDK is a B2B integration surface. Partner applications embed it to access the BP measurement capability. SDK versioning strategy (semantic versioning, deprecation policy, compatibility matrix) is defined in Layer 12 (Mobile Architecture).
