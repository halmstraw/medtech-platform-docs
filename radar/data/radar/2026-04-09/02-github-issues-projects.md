Planning and requirements traceability. Keeps the full chain — issue → branch → PR → build → deploy — within one system with one audit trail. No synchronisation overhead, no separate user management, and no context switching between tools.

At this team size (fewer than 20 people), Jira's overhead is not justified. GitHub Projects provides milestone-based planning that maps directly to the four delivery phases. See **DEC-003**.
