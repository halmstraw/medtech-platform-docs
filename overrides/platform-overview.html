Medical Device Platform — On a Page

Class IIa rPPG-based vital signs monitoring · Azure · iOS & Android SDK
IEC 62304 ISO 13485:2016 EU MDR Class IIa FDA 510(k) / De Novo ISO 14971 GDPR NHS DSPT
Business Context

Product: A smartphone camera captures micro colour changes in facial skin (remote photoplethysmography). The RGB signal is processed by cloud ML algorithms and returns systolic/diastolic blood pressure and pulse rate. No cuff, no hardware, no contact.

Challenge: The science is clinically validated — the engineering wrapper needs to mature to FDA-submission standard while reducing per-assessment cost from ~7p to under 1p and multiplying a small team's throughput through AI-assisted tooling.

Infrastructure

Azure with Terraform IaC. AKS for container orchestration, replacing per-assessment container spin-up. Key Vault for secrets.

Terraform AKS Key Vault Azure Monitor
10

Observability

Grafana + Prometheus for metrics, Loki for logs, Sentry for error tracking. PagerDuty for on-call routing. Full stack visibility.

Grafana Prometheus Loki Sentry
11

Mobile Architecture

iOS (Swift/SwiftUI) and Android (Kotlin) SDK built on MVVM and Clean Architecture. rPPG signal capture isolated behind a platform-agnostic abstraction layer. Semantic versioning and B2B compatibility matrix for partner integrations.

Swift / SwiftUI Kotlin Fastlane GitHub Actions
12

Security Architecture

STRIDE threat modelling applied to the rPPG assessment flow. Data classification, encryption at rest and in transit, on-device anonymisation before cloud transmission. SBOM as FDA cybersecurity artefact. Builds on Cyber Essentials Plus baseline.

Snyk Key Vault SBOM (Syft) Trivy
13

AI Engineering Strategy

Anthropic API as primary agentic framework. LLM tooling selected for data residency, audit trail, and no training on proprietary code. Trust zone model governs all agent activity. Guardrails prevent AI-generated code entering production without human review.

Claude API GitHub Actions
14

Developer Experience

GitHub Pages for documentation (phase 1), Backstage for internal developer portal (phase 4). SDK versioning strategy for B2B partners.

GitHub Pages Backstage
15

Maintenance & Automation

Automated dependency updates, vulnerability scanning, SBOM generation, and secret rotation — keeping the platform secure and current without dev time. Patch-level security fixes auto-merge; changes touching clinical dependencies are flagged for review.
